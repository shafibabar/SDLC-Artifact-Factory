SKILL GEN Insights Build Guide

You'll create fifteen charts on the SKILL GEN Project (#1266, sub-issue #1273). The data fields behind them are already on the board. Each card below holds the exact settings: copy the name, set the four dropdowns, paste the filter, then save.

  1. Open the project's Insights. The built-in Burn up chart can stay.
  2. Click + New chart in the left menu.
  3. Rename it: click the ▾ next to the chart name, paste the Name, and press Return.
  4. Click Configure and set Layout, X-axis, Group by and Y-axis exactly as the card shows.
  5. Paste the Filter into the box above the chart, then click Save changes.
  6. Tick the card's Built box. The ticks stay saved in this browser.

If a setting is missing. GitHub doesn't document every option for user-owned projects. If Time isn't offered on the X-axis (that makes a historical chart), or a field won't appear in a dropdown, use the card's fallback line and tell Claude which one you used.

Data is still filling in. The backfill writes about 19,000 values in the background. Charts recompute live, so you can build them now; the bars grow as it finishes.
