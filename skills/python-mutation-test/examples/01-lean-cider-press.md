Every file below was extracted from this page into a fresh project and run with Python 3.14.4, uv 0.13.9 and mutmut 3.8.1 (macOS arm64, 2026-11-28); the outputs are copied from those runs, trimmed only where marked.

### `src/ciderpress/domain/slots.py`

```python
"""Booking rules for the community cider press."""


def is_late(minutes_after_start: int, grace_minutes: int) -> bool:
    """A group is late once it arrives more than the grace period after its slot starts."""
    return minutes_after_start > grace_minutes


def crates_allowed(requested: int, limit: int) -> int:
    """A group presses at most `limit` crates per slot."""
    if requested > limit:
        return limit
    return requested
```

### `src/ciderpress/domain/pressing.py`

```python
"""How many pressings a load of apples needs."""


def pressings(apples_kg: int, kg_per_press: int) -> int:
    count = 0
    remaining = apples_kg
    while remaining > 0:
        remaining -= kg_per_press
        count += 1
    return count
```

### `src/ciderpress/domain/juice.py`

```python
"""Expected juice from a load of apples."""


def juice_litres(apples_kg: int) -> int:
    return apples_kg * 6 // 10
```

### `src/ciderpress/service_layer/booking.py`

```python
"""Book a pressing slot."""
from typing import Protocol

from ciderpress.domain.slots import crates_allowed


class Slots(Protocol):
    def reserve(self, group: str, crates: int) -> int: ...


class BookingDesk:
    def __init__(self, slots: Slots, crate_limit: int) -> None:
        self.slots = slots
        self.crate_limit = crate_limit

    def book(self, group: str, crates: int) -> int:
        granted = crates_allowed(crates, self.crate_limit)
        return self.slots.reserve(group, granted)
```

## What the agent does

1. Setup from the templates; `validate-python-mutation-setup.sh .` until `0 FAIL, 0 WARN`.
2. Commit; `make mutation`. The runner deletes `mutants/`, runs mutmut (exit 0 despite survivors), reruns the two timed-out mutants with `timeout_multiplier 60` in a copy, and writes `mutation-out/`.
3. Triage each mutant not caught (`../references/triage-in-python.md`); write the missing rows; record what cannot be killed; run again until PASS.
