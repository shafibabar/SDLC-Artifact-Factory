# Canvas Coherence Check

Self-contained. Run this after every block is filled and before handing the canvas off; re-run it after any block changes. It checks the **fit between blocks**, which is what makes a canvas more than a list. Run the **core** questions, then the set for your variant, then the pattern's checks if a pattern applies. Any "no" means the block holding the gap is revised and the check re-run. Record each answer (pass / revise, with the block named) in the artifact's Coherence Check section.

The full canvas's activity, resource and partnership questions do not apply to a Lean Canvas, which has none of those blocks; the Lean set replaces them.

Sources: Osterwalder and Pigneur, *Business Model Generation*; Maurya, *Running Lean*; Ramanujam and Tacke, *Monetizing Innovation*; Osterwalder et al., *Value Proposition Design*.

---

## Core: both variants

| # | Question | Typical gap |
|---|---|---|
| C1 | Does every value entry (Value Propositions or UVP) address a named segment's **top-ranked** pain, gain or problem, and name the alternative it beats? | A benefit no segment ranked; feature-first wording |
| C2 | Does every Channel reach the segment it serves (the Early Adopters, on a Lean Canvas)? | Channels aimed at the eventual market |
| C3 | Does every Revenue Stream come from a segment that receives a value proposition, at a charging unit that tracks that value, **inside the segment's recorded willingness-to-pay range** (or with WTP marked unknown and a test)? | A stream nobody receives value for; a price far below the range (value left uncaptured) or with no WTP evidence at all |
| C4 | Does the Cost Structure include customer acquisition cost and cost to serve, and does a Fermi estimate show revenue can plausibly cover cost at a realistic conversion? | Infrastructure-only costs; a model that cannot pay for itself at any conversion |
| C5 | Does at least one item survive the copy-or-buy filter, and is it consistent with the strategy kernel's advantage? Lean: or is the Unfair Advantage honestly `unknown: tested by …`? | "First mover", "great team"; an advantage the kernel never relied on |
| C6 | Does every block carry exactly one evidence status, with no bare TBD (`unknown: tested by …` allowed on a Lean Canvas only)? | Missing statuses; "validated" on stated interest |
| C7 | Are the top risks (two at lean, three otherwise) typed product / customer / market, each with a falsifiable hypothesis, a success criterion and a time box? | "Validate with customers" |
| C8 | Does nothing on the canvas pursue a direction the strategy kernel's guiding policy rules out? | A segment or channel the kernel excluded |
| C9 | (standard, enterprise) Does each value entry trace to that segment's Value Proposition Canvas, with every pain reliever and gain creator mapped to a ranked pain or gain, and jobs cited from `jtbd-analysis` or marked hypothesis for it? | A value block written from the feature list |
| C10 | If a business model pattern applies, do all its extra checks pass (`../references/business-model-patterns.md`)? | Freemium with no cost per free user or fence |

## Full canvas only

| # | Question | Typical gap |
|---|---|---|
| B1 | Do the Key Activities produce the value propositions, and is there no key activity that serves nothing else on the canvas? | Activities listed because the company does them |
| B2 | Does every Key Activity have the Key Resource it needs? | An activity no one can perform |
| B3 | Is every Key Partnership real or realistically signable in the planning horizon, with its motivation stated? | Aspirational partners; customers listed as partners |
| B4 | Can the Cost Structure fund each segment's Customer Relationship at that segment's price? | Dedicated assistance at a self-serve price |
| B5 | Do the Cost Structure's main items map back to Key Activities, Key Resources and Partnerships? | Costs from nowhere, or activities that cost nothing |

## Lean Canvas only

| # | Question | Typical gap |
|---|---|---|
| L1 | Do the Early Adopters actually hold the top-ranked Problem, and is it one canvas per segment whose problems differ? | Early adopters = "everyone"; two segments blended on one canvas |
| L2 | Are Existing Alternatives named for each Problem? | Blank, or "no competitors" |
| L3 | Does the UVP speak to the top Problem as one message, not a feature list? | Five benefits; a feature name |
| L4 | Does each Solution item map to a listed Problem, with nothing extra? | Features nobody's problem asked for |
| L5 | Is each Key Metric a rate or cohort number tied to an AARRR step, with the bottleneck marked? | Cumulative sign-ups; page views |
| L6 | Are the Problem/Solution Fit exit criteria written as checkboxes? | "Migrate when it feels validated" |

## Re-run triggers

A test result changes a block's evidence status; a segment is added or dropped; the kernel is revised; a launch-stage move; before the next OKR cycle.
