# Master Artifact-Type Catalog

STUB — filled by sub-issue #256 (Content: artifact-type-catalog and manifest-worked-example references).

One row per artifact type this plugin can produce: Artifact Type, Producing Agent, Skill Used, File Path Pattern, Phase, and Required Frontmatter Fields. This is a representative cross-section across phases, not an exhaustive list of the ~130 skills — it exists to demonstrate the pattern. Every skill in `skills/*/` that produces a distinct output artifact has a row of this shape; the full catalog is maintained by extension as new skills are added. Moves the master catalog table out of `SKILL.md`'s decision-shaping guidance, since the table itself is reference material — consulted when an agent needs to look up a specific artifact type's producing agent, path pattern, or required frontmatter, not read start-to-end on every invocation.
