## Check-In Guide — [Product], [participant role, organisation], [date]

Run by: [the user or the design partner's session lead]. The agent drafts this guide and works from the notes afterwards; it does not hold the conversation.

**Framing (said, not asked):** "No demo today — I'd like to hear how [the work] went since we last spoke."

1. **Story prompt:** "Tell me about the last time you [did the job this release touches]. Where did it start?"
2. **Excavate:** "What happened next?" · "Who else was involved?" · "What was the hardest part?"
3. **Friction:** "Was there a point where you stopped or worked around something? What did you do instead?"
4. **Before the product:** "Before this, what did you do the last time this came up?"
5. **The question you'd rather not ask:** "Is this a priority for you this quarter? What's ahead of it?"
6. **Commitment:** "Could we [watch you run the next one / get the next session in the diary / meet the colleague who …]?"

**Rewrite before the call:** every "would you…", "do you think…" and "how much would you pay…" becomes a past-tense, specific-instance question.

**Afterwards:** one feedback item per finding; compliments and fluff not logged; ideas converted to the underlying need.
