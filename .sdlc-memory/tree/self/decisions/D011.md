# D011: Content improvement campaign before Chunk 15: full per-file pass over all skills, agents, and repo metadata, delivered as five batch PRs.

**Date:** 2026-07-19

**Rationale:** A stronger model became available; three parallel audits found generational drift in agents, frontmatter schism, stale metadata, dead references, and terminology drift. Fixing before building Chunk 15 prevents propagating the drift into new components.

**Alternatives rejected:**
- Targeted fixes only — audit sampled ~20% of skills, so unsampled files would get no fresh scrutiny
- Single campaign PR — a ~120-file diff is not PM-reviewable in one sitting
