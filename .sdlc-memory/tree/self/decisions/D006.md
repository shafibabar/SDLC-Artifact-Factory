# D006: Frontend stack: React + TypeScript

**Date:** 2026-06-24

**Rationale:** The first product requires graph visualization (Obsidian-style) and compliance dashboards. React has mature graph libraries (D3, Cytoscape, Sigma.js). Component-level reactivity suits dashboards. HTMX+templ would create ongoing pain for the graph view.

**Alternatives rejected:**
- HTMX + templ — insufficient for complex graph visualization
- Vue — viable but React has richer graph library ecosystem
