# D044: Every agent's standard tool set includes Skill, so the methodology hook can review artifacts an agent writes (#1290)

**Date:** 2026-10-19

**Rationale:** Dogfood v3 found every Strategy artifact written by product-strategist came back "Methodology review could not run: No such tool available: Skill". A probe confirmed that an agent-type hook fired by a subagent's tool call runs with that subagent's tools, and the #1254 standard set (`Read, Write, Edit, Glob, Grep, Bash`) had no `Skill`, so the hook (which loads `methodology-review` through the Skill tool, D041/#1255) failed closed on every agent-written artifact. #1255's live test wrote from the main session, which always has Skill, so it missed this. All 13 agents now declare `tools: [Read, Write, Edit, Glob, Grep, Bash, Skill]`, `schemas/agent.schema.json` enforces the exact set, and live `hooks-wiring` case 5 has an agent (not the main session) write the artifact and checks the hook loads the skill and returns a verdict.

**Alternatives rejected:**
- Have the hook Read the skill file instead — rejected: hook subagents can't Read plugin files from a product repo and hook prompts don't expand `${CLAUDE_PLUGIN_ROOT}` (the #1255 finding).
- Inline the review criteria in the hook prompt — rejected: duplicates `methodology-review` in a second place that would drift.
- Add Skill only to agents that write artifacts — rejected: every agent writes artifacts, and one uniform, schema-enforced set is simpler to verify.
