**Date:** 2026-07-20

**Rationale:** Each bug was found by actually invoking the hook with a real or synthetic trigger and checking the outcome, not by reading the script. The naming-convention bug in particular would have silently shipped a non-functional governance check — a live end-to-end test (create a badly-named file, confirm it's rejected) caught what a code read did not.

**Alternatives rejected:**
- Ship without live-testing each script individually — rejected per the standing practice this session established in Chunk 19 (D012)
