# D009: Canonical component frontmatter schemas — SKILL.md: name/description/version/phase/owner/created/tags; AGENT.md: name/description/role/version/phase/owner/created/inputs/outputs/skills/tools/tags. Emitted artifact templates use the key 'name:', never 'artifact:'.

**Date:** 2026-07-19

**Rationale:** Three incompatible frontmatter shapes had emerged across build chunks (CLAUDE.md artifact standard, README component specs, on-disk reality). One machine-readable schema per component type restores introspectability and lets governance hooks validate uniformly.

**Alternatives rejected:**
- Keeping the lean Gen-2/3 agent frontmatter (name/description/version/phase/tags) — loses machine-readable inputs/outputs/skills/tools wiring
- Renaming CLAUDE.md's required 'name' field to 'artifact' — would ripple into every governance rule
