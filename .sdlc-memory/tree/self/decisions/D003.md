# D003: Skills organized by knowledge domain, not SDLC phase

**Date:** 2026-06-24

**Rationale:** DDD, TDD, BDD apply across multiple phases. Phase-locked skills cause duplication or get skipped when the phase doesn't match. Domain organization makes skills reusable across phases.

**Alternatives rejected:**
- Phase-locked skills (strategy/, ideate/, design/, implement/ etc.) — used in old build, caused duplication
