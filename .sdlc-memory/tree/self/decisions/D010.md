# D010: Behavioral Directives in agents are an accepted pattern: a compressed index of imperative bullets, each citing the owning skill. Decision criteria/tables in skills are knowledge, not reasoning.

**Date:** 2026-07-19

**Rationale:** Codifies two boundary clarifications to the component anti-pattern rules. Directives whose substance is absent from the cited skill remain defects — the substance moves into the skill.

**Alternatives rejected:**
- Strict reading — stripping all directive content from agents into skills; loses the at-a-glance engineering contract without reducing duplication
